Accessibility — WCAG 2.2 AA

Focus

3px Smart Green ring, 2px offset, never outline:none without replacement.

Targets

≥ 24×24 CSS px desktop · ≥ 44×44 touch. Tabs sit at 40px, primary buttons at 40px, sm at 32px (with adequate spacing).

Semantics

Buttons are <button>. Tabs use role="tab" + aria-selected. Form errors use aria-invalid + aria-describedby. Toasts use role="status".

Reduced motion

prefers-reduced-motion: reduce collapses every motion token to ≤ 50ms. No transform animations on critical paths.

Command Palette v2.1 · interactive

The first worked example against §11. WAI-ARIA APG 1.2 combobox with aria-activedescendant; the input keeps focus while the active row moves. Try it: Ctrl + K (or ⌘ + K) anywhere on this page.

Full component contract docs/components/command-palette.md

Keyboard map

  • Ctrl+K — open
  • ↑ ↓ — navigate
  • ↵ — invoke
  • Esc — clear, then close
  • Tab — close (deliberate)

Why activedescendant

Real focus stays on the <input> the entire time. Moving real focus into the listbox would break continued typing. The "active" row is communicated via aria-selected="true" and the input's aria-activedescendant pointer.

Tab closes

A divergence from typical dialog focus-traps. A command palette is transient; keyboard users expect Tab to leave the way it leaves a menu. The footer is therefore decorative — by design. See doc §9.

Token naming

primitive → semantic → component

// primitive (raw)
--dgo-green-700: #05583B;

// semantic (intent)
--dgo-color-action-primary: var(--dgo-green-700);

// component (binding)
--dgo-btn-bg-primary: var(--dgo-color-action-primary);

Semver & deprecation

  • MAJOR — breaking removals (1 minor warning required)
  • MINOR — additive tokens, components, themes
  • PATCH — visual fix, no API change
  • @deprecated CSS comment + console warn on use
  • RFCs for any new component family
  • Six-month notice on token / class / attribute renames

Decision paths

  1. PATCH — direct PR, one review.
  2. MINOR additive — issue → PR, two reviews + family owner.
  3. MAJOR breaking — RFC required; deprecation ships in the prior minor.
  4. RFC — new component family, theme, density, or template change. Two-week clock + steward sign-off.
