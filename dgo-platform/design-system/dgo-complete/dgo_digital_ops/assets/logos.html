Usage Notes

  • Horizontal Primary: Default for headers, wide spaces, web banners
  • Horizontal + Endorsement: Official documents, login screens, letterhead
  • Stacked: Compact spaces, mobile headers, square lockups
  • Mark Only: Favicons, app icons, social profile pictures (48×48px minimum)
  • White-out: On Deep Green backgrounds, dark surfaces, or photography with dark backing
  • Compact: Minimum size = 120px wide; below this, use mark only

Clear space = height of atomic-O symbol on all sides. Never rotate the orbit. Never change dot position.
